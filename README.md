# deliveryPizza

Frontend for the deliveryPizza project, built with Next.js.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. You can edit the page in `app/page.js`; changes are reflected automatically.
